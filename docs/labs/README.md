# Labs

The labs use observation and synthetic configuration rather than proprietary
source. Complete them in order or select the one that matches your goal.

| Lab | Outcome |
| --- | --- |
| [1. Observe the surface](01-observe-the-surface.md) | Capture a safe version/help snapshot and classify responsibilities |
| [2. Prove config precedence](02-prove-config-precedence.md) | Observe global-to-local provenance in a preflight-checked temporary directory |
| [3. Design a plugin eval](03-design-a-plugin-eval.md) | Create a balanced capability-quality test plan |
| [4. Measure reliability](04-measure-agent-reliability.md) | Separate iterations, retries, and validation |
| [5. Build a scorecard](05-build-an-improvement-scorecard.md) | Pair readiness probes with outcome measures |

Each lab identifies the claim IDs it demonstrates. Store local evidence under
`.artifacts/` and do not commit it.
